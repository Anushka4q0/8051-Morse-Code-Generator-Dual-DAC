# 8051 Morse Code Generator with Dual DAC Interface

Project Overview:
Designed and implemented a Morse Code Generator on an 8051 microcontroller using Embedded Assembly Language.

Features:
- Converts text into Morse DOT/DASH pulse sequences
- Generates digital output through Port-1
- Interfaces with Dual DAC hardware
- Verified output using Digital Storage Oscilloscope and Logic Analyzer

Hardware Used:
- 8051 Microcontroller Development Board
- Dual DAC Module
- Digital Storage Oscilloscope
- Logic Analyzer

Software Used:
- Keil uVision
- Embedded Assembly Language
